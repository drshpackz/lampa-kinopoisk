# Кинопоиск — плагин для Lampa

Плагин добавляет **Кинопоиск как полноценный источник данных** в Lampa. Это не
отдельный экран с чужими карточками: Кинопоиск встраивается туда же, где живёт
TMDB, поэтому по кинопоисковой базе работают лента, сетка «ещё», карточка
фильма, сезоны и серии, поиск и страницы актёров.

Данные берутся из [api.poiskkino.dev](https://poiskkino.dev/documentation)
(зеркало kinopoisk.dev): русские названия, описания, рейтинг КП и IMDB,
постеры Кинопоиска, актёры, похожие, сиквелы и приквелы.

## Установка

1. Lampa → **Настройки → Расширения**.
2. Добавьте плагин по ссылке:
   ```
   https://drshpackz.github.io/lampa-kinopoisk/kinopoisk.js
   ```
3. Перезапустите Lampa. В левом меню появится пункт **«Кинопоиск»**.

> **Вставьте свой токен.** Встроенный токен — общий на всех, кто поставил плагин
> по этой ссылке, а лимит у него 200 запросов в сутки на всех вместе. Свой токен
> берётся за минуту у бота [@poiskkinodev_bot](https://t.me/poiskkinodev_bot) и
> вставляется в **Настройки → Кинопоиск → Токен API**. Без него плагин будет
> работать в основном из кеша.

## Что появляется в приложении

- **Пункт «Кинопоиск» в меню** — открывает главную ленту на кинопоисковой базе.
- **Кинопоиск в списке источников** (Настройки → Основные → Источник). Если
  выбрать его, на Кинопоиск переключается всё приложение: главная, «Фильмы»,
  «Сериалы», поиск. TMDB остаётся источником по умолчанию — плагин только
  добавляет вариант.
- **Вкладка «Кинопоиск» в общем поиске** — рядом с TMDB и CUB.
- **Раздел «Кинопоиск» в настройках** — токен, суточный лимит, счётчик
  израсходованных запросов и кнопка очистки кеша.

### Ряды главной

`Сейчас в кино` · `Популярные фильмы` · `Популярные сериалы` · `Новинки кино` ·
`Новые сериалы` · `Топ 250 Кинопоиска` · `Лучшее по версии зрителей` ·
`Российские сериалы` · `Аниме` · `Мультфильмы`, затем жанровый каталог
(боевики, комедии, драмы, триллеры, фантастика, ужасы, детективы, мелодрамы,
криминал, приключения, фэнтези, военные) — всего 22 ряда.

Ряды на датах (`Сейчас в кино`, новинки) считаются от текущего дня, так что
лента не устаревает на зашитом годе.

## Про лимит запросов — прочитайте, это главное

**У бесплатного токена всего 200 запросов в сутки.** Не 200 в минуту — в сутки.
Один ряд ленты = один запрос, одна карточка фильма = один запрос (сериал — два,
вместе со списком сезонов). Без кеша обычный вечер просмотра съел бы лимит за
двадцать минут, поэтому весь сетевой слой построен вокруг него:

- **Кеш разобранных ответов** в `Lampa.Storage` (ключ `kp_cache`, до 90 записей,
  вытеснение самых старых). Ряды живут 12 часов, карточки и сезоны — неделю,
  поиск — 2 часа. Повторное открытие той же ленты стоит **ноль** запросов.
- **Штатный кеш Lampa** (`cache.life`) — вторым слоем. Он полезен тем, что при
  ошибке отдаёт устаревшую копию.
- **Счётчик квоты.** Плагин сам считает израсходованное за сутки и, упёршись в
  лимит, перестаёт ходить в сеть: показывает сохранённые данные и один раз
  предупреждает. Лента продолжает открываться, просто не обновляется.
- **Очередь запросов** — не больше двух одновременно и 220 мс между стартами,
  под ограничение Кинопоиска в 5 запросов в секунду.
- **`selectFields`** — с сервера запрашиваются только нужные карточке поля.
  Полный документ Кинопоиска весит в разы больше, а на телевизоре это заметно.

Если у вас свой тариф — вставьте личный токен в **Настройки → Кинопоиск →
Токен API** (получить: бот [@poiskkinodev_bot](https://t.me/poiskkinodev_bot))
и поднимите там же суточный лимит. Смена токена очищает кеш.

## Как устроено

Один файл `kinopoisk.js`, чистый ES5, зависимости — только глобальные `Lampa`
и `$`. Плагин регистрирует объект источника:

```js
Lampa.Api.sources.kp = { main, list, category, full, search, discovery,
                         person, seasons, menu, menuCategory, ... }
```

и дальше Lampa сама вызывает нужный метод по `source: 'kp'` в активности.

### Кинопоиск → карточка Lampa

Две вещи, которые нельзя нарушать (обе закреплены тестами):

1. **Фильм получает только `title`/`original_title`, сериал — только
   `name`/`original_name`.** Lampa решает, чем открыть карточку, по наличию
   `original_name` (`router.add('full')`: `method = data.original_name ? 'tv' :
   'movie'`). Если проставить оба поля, фильм откроется как сериал.
2. **`poster_path` не заполняется никогда.** У Кинопоиска готовые абсолютные
   URL, а `Api.img()` всегда подставляет хост TMDB. Картинки идут в `poster`,
   `img` и `background_image` — их Lampa берёт как есть.

Рейтинг Кинопоиска кладётся в `vote_average`: на полной карточке Lampa
переименовывает первый бейдж в имя источника, так что он и подписан «KP».
Отдельного `kp_rating` нет — иначе та же оценка выводилась бы дважды.
`imdb_id` и `kinopoisk_id` проставляются всегда: по ним работают
онлайн-балансёры.

### Сезоны

`/v1.4/movie/{id}` **не возвращает `seasonsInfo`**, поэтому сезоны и серии
всегда берутся из `/v1.4/season` — он и есть источник правды. Карточка сериала
и экран серий делают один и тот же запрос, так что открытие списка серий после
карточки бесплатно. Нулевой сезон (спецвыпуски) в счётчик сезонов не идёт, но
в списке остаётся.

### Чего нет

- **Трейлеры.** Кинопоиск отдаёт ссылку на свой embed-плеер без YouTube-ключа,
  а плеер трейлеров Lampa ждёт именно ключ. Показывать заведомо нерабочую
  кнопку хуже, чем не показывать никакой, поэтому `videos` не заполняется.
- **Страница студии** (`company`) и серверное «Избранное» (`favorite`) —
  заглушки: у Кинопоиска нет соответствующих ресурсов в этом API.
- **Фильмография актёра** отдаётся одним блоком: `/v1.4/person/{id}` не
  сообщает, фильм это или сериал, поэтому все работы открываются как фильмы.

## Настройка выдачи

Ряды лежат в `kinopoisk.js`: `catalogRows()` (даты, топы, популярное) и
`GENRE_ROWS` + `genreRows()` (жанровый каталог). Синтаксис фильтров —
кинопоисковый, не TMDB:

- **жанр** — `genres.name=<русское название>` (обязательно закодированное);
- **тип** — `type=movie|tv-series|cartoon|anime|animated-series`;
- **порог популярности** — `votes.kp=1000-10000000`;
- **рейтинг** — `rating.kp=7-10`;
- **год** — `year=2025-2026`, **дата премьеры** — `premiere.russia=дд.мм.гггг-дд.мм.гггг`;
- **коллекция Кинопоиска** — `lists=top250`;
- **сортировка** — `sortField=votes.kp&sortType=-1`.

Сколько рядов грузится за раз — `parts_limit` в `main()` (по умолчанию 5,
остальные подтягиваются прокруткой). Время жизни кеша — `LIFE`.

## Тесты

```bash
npm test              # 70 юнит-тестов на моке Lampa: без сети и без расхода квоты
npm run test:live     # живая проверка против api.poiskkino.dev (~13 запросов из 200)
npm run test:browser  # плагин внутри настоящей Lampa в браузере (~8 запросов)
```

`npm test` намеренно ограничен `test/*.test.js`: живые проверки тратят реальную
суточную квоту, поэтому запускаются только вручную.

Юнит-тесты гоняют плагин на моке Lampa (`test/helpers/lampa-mock.js`) — они
быстрые и ничего не тратят, но мок не скажет, что запрос составлен неверно.
Поэтому есть две живые проверки:

- **`live-check.js`** — реальные ответы Кинопоиска через настоящий сетевой слой
  плагина: ряды, карточка фильма, сериал с сезонами, поиск. Она уже находила
  две настоящие ошибки (отсутствие `seasonsInfo` и коллизию ключей кеша).
- **`browser-check.js`** — Lampa целиком в headless-браузере: плагин
  устанавливается в работающее приложение, открывается лента, карточка
  открывается нажатием Enter, проверяются источник активности, картинки и
  бейджи рейтинга. Нужен запущенный билд Lampa:

  ```bash
  git clone --depth=1 https://github.com/yumata/lampa /tmp/lampa
  python3 -m http.server 8901 --directory /tmp/lampa &
  NODE_PATH=<путь к node_modules с playwright> npm run test:browser
  ```

  Скриншоты кладутся в `test/live/shots/`.
